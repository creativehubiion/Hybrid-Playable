# Electoral Commission NZ — brand kit

Mock hybrid-poll unit for the Electoral Commission NZ / Te Kaitiaki Take Kōwhiri
"enrol to vote" campaign.

- **Variant:** direct (`simple.html`) — video + poll both appear on load, no start gate.
- **Font:** Montserrat (matches vote.nz) — Google Fonts, weights 400/500/700.
- **Video:** `video.mp4` — EC NZ "Why is it important to enrol to vote?" street vox-pop.

## Palette (from the vote.nz style guide)

| Token | Hex | Used as |
|---|---|---|
| accessible-orange | `#d24600` | `--accent` (CTA, selected, video label) |
| dark-red | `#aa2e00` | `--accent-light` (numbers, %, confirmation button) |
| karaka-orange | `#ff7300` | `--bg-card` (gradient top) |
| campaign yellow | `#ffd200` | `--bg` (gradient bottom) |
| standard-black | `#231f20` | `--text`, video letterbox |
| standard-orange | `#f89628` | (reference) brand orange |
| d4-orange | `#d43900` | (reference) |
| grey | `#666666` | (reference) muted |

The poll background continues the video's karaka-orange→yellow gradient so the two panels
read as one unit. Option cards are translucent white; the submitted button uses dark-red
(on-brand) rather than the template's default green.
